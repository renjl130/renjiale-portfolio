# 任佳乐个人作品集 | Ren Jiale Portfolio

任佳乐的个人作品集，记录产品、内容、品牌传播、海外运营、影像制作与校园实践。

## 在线访问

- GitHub Pages: https://renjl130.github.io/renjiale-portfolio/

## 本地运行

```bash
npm install
npm run dev
```

访问 http://localhost:3100 查看网站。

## 构建

```bash
npm run lint
npm run build
```

项目使用 Next.js、React、TypeScript 与 Framer Motion 构建，并通过 GitHub Pages 静态托管发布。
