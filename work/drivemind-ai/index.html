问题与背景

传统车载语音助手只能被动响应指令，无法感知驾驶场景的变化。驾驶员在高速、复杂路况或疲劳状态下，需要主动式、低打扰的智能辅助，而非又一个需要唤醒词的聊天机器人。

企业级 PoC 项目，目标是验证主动式座舱 Agent 的可行性，并明确从 Demo 到量产的能力边界与技术约束。

产品方法

  1. 场景建模：梳理驾驶全流程中的高频场景——出发规划、途中导航、疲劳提醒、到达总结，识别 AI 主动介入的合理时机。
  2. Agent 架构：设计“感知—规划—执行—记忆”四阶段闭环，将摄像头状态、车辆遥测和对话上下文统一编排为主动事件。
  3. 隐私边界：定义数据采集范围、存储策略和会话级状态隔离机制，确保用户隐私不因主动感知而泄露。
  4. 降级策略：设计真实模型和规则降级的双路径方案，确保 AI 能力不可用时系统仍能安全运行。

关键决策

主动介入必须有明确触发条件

AI 不应“随意发言”。每次主动交互必须绑定可解释的触发事件（如检测到疲劳、偏离路线），避免驾驶员被打扰。

会话级状态隔离保护隐私

不同驾驶员的对话历史、偏好和行为数据完全隔离。车辆共享场景下，前一位驾驶员的数据不会泄露给下一位。

Mock 与真实模型并行验证

PoC 阶段同时维护 Mock 数据路径和真实模型路径，确保 Demo 的稳定性不依赖模型的实时表现。

成果

  • 完成企业级 PoC，包含端到端 Demo 和评审脚本，可独立演示完整场景。
  • 明确 Mock、隐私与量产能力边界，为后续立项提供技术评估依据。
  • 设计会话级状态隔离和双路径降级方案，确保系统在各种条件下安全可控。
